# Exercice 3 : relire un test proposé par un assistant IA

Le test `avant.spec.js` ressemble à ce qu'un assistant propose souvent pour « tester le parcours de commande ». Il passe.

1. Listez ce qu'il vérifie vraiment (indice : cherchez la dernière ligne).
2. Repérez au moins trois défauts : sélecteurs fragiles, erreur avalée, assertion qui ne prouve rien, cas d'échec absent.
3. Videz le panier mentalement : ce test échouerait-il si la commande était refusée ?
4. Réécrivez-le, puis comparez avec `solutions/03/`.

Pour relire n'importe quel test généré, la [grille de revue des tests IA](https://www.automationdatacamp.com/grille-revue-tests-ia?utm_source=github&utm_medium=referral&utm_campaign=playwright-practice-lab&utm_content=exercice-3) donne 7 points à vérifier.
